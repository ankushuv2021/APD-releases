# APD Downloader — Releases

Download manager for Windows. Faster downloads, proper pause and resume, and
video capture from the browser.

## Download

**[Get the latest release](https://github.com/ankushuv2021/APD-releases/releases/latest)**

Download `APD_Setup_X.X.X.exe` and run it. Windows 10 or 11, 64-bit.

Upgrading? Just run the installer — it upgrades in place and keeps your
settings, history and downloads. No need to uninstall first.

## Browser extension

APD captures downloads from your browser once the extension is installed:

**[APD - Download Manager on the Chrome Web Store](https://chromewebstore.google.com/detail/kimlkhkemppkmcohaoobkincdbmoedbk)**

Works with Chrome, Edge and Brave. It connects to the desktop app by itself the
first time you use it — nothing to configure.

The extension does nothing on its own. Install the desktop app first.

## What it does

- Splits downloads across multiple connections
- Pause and resume, including after a crash or restart
- Captures downloads from the browser automatically
- Downloads video from pages, including HLS and DASH streams
- Torrent support
- Updates itself — Settings → About → Check for Updates

## Requirements

- Windows 10 or 11, 64-bit
- Microsoft Edge WebView2 Runtime — already present on current Windows; the
  installer fetches it automatically if missing

## Privacy

APD collects nothing. No accounts, no telemetry, no analytics. Everything stays
on your computer.
